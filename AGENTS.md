# AGENTS.md

## Regra obrigatória

Toda alteração feita neste repositório **deve** ser commitada e pushada imediatamente após ser concluída e verificada.

Siga sempre este fluxo:

1. Faça a alteração no código.
2. Execute `git add .`
3. Execute `git commit -m "mensagem descritiva da alteração"`
4. Execute `git push`

Nunca deixe alterações sem commit ou sem push.
